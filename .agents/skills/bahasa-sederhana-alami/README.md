# Bahasa Sederhana Alami — skill penulisan ulang

Skill ini mengubah tulisan formal/akademik menjadi bahasa sederhana seperti tulisan orang yang belum terbiasa menyusun artikel, dengan tetap menjaga data dan makna.

## Isi ZIP
- `SKILL.md`: definisi skill dan instruksi inti.
- `references/contoh.md`: contoh singkat penggunaan.

## Cara pakai
1. Ekstrak ZIP.
2. Jika aplikasi/agen AI Anda mendukung skill berbasis `SKILL.md`, salin folder `skill-bahasa-sederhana` ke direktori skills yang ditentukan aplikasi tersebut. Cara pemasangan mengikuti aplikasi masing-masing.
3. Minta: `Gunakan skill bahasa-sederhana-alami untuk rewrite teks berikut: ...`

Catatan: ZIP ini adalah paket skill siap pakai, tetapi pembuatan file ZIP **tidak secara otomatis memasang** skill ke akun ChatGPT atau ke semua percakapan.
